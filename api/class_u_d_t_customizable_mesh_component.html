◆ SetSlotOption()

bool UDTCustomizableMeshComponent::SetSlotOption ( FName ParameterName,
FName OptionName,
const TArray< FDTMeshParameterOverride > & ParameterOverrides )

Select an option on a slot parameter and record parameter overrides held while it is active.

When several active slots override the same parameter, the most recently applied wins; releasing it falls back to the next holder, then to the baseline value.

Parameters
ParameterNameCustomizable Object parameter to change (e.g. "Helm Group").
OptionNameOption / table row to select (e.g. "Helm_01").
ParameterOverridesParameters forced to specific options while this slot is active (e.g. "Hair Mode" = "Hidden").
Returns
true if the slot state was recorded.
