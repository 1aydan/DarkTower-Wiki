◆ UpdateAudioListenerOverride()

void ADTPlayerController::UpdateAudioListenerOverride ( )
protected

Anchors the audio listener to the possessed pawn's camera boom focus point instead of the camera itself.

By default UE puts the listener on the camera, which rides the RPG camera boom 500-1600cm back from the character depending on zoom. That makes every attenuated sound quieter as the player zooms out and shifts the near/far balance of the mix, since attenuation curves aren't linear. Anchoring to the boom's focus point takes zoom out of the equation entirely while keeping the camera's orientation, so left/right panning still matches the screen.
