Detailed Description

A single ability granted by an ability set, addressed for input by gameplay tag.

Property names are preserved from the GASCompanion FGSCGameFeatureAbilityMapping this replaced, so serialized data in DA_AB_* / DA_Ability_* assets survives the struct redirect. The old InputAction / TriggerEvent members were intentionally dropped in favor of InputTag.
