Detailed Description

The per-actor GAS hub for Dark Tower.

Abstracts owner/avatar setup for the Ability System Component (which lives on the PlayerState for players) and relays attribute/effect/ability/tag changes to Blueprint-assignable delegates. Every DT actor reaches GAS through this component via IDTAbilityTarget::GetAbilityCoreComponent().
