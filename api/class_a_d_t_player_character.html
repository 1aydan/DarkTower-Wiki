◆ GetAimGroundLocation()

FVector ADTPlayerCharacter::GetAimGroundLocation ( float MaxDistance = 0.0f) const

World-space ground aim point for cast-at-location targeting.

Resolves under the mouse cursor when mouse-aiming, or projected along the current aim direction when gamepad-aiming. The result is snapped to the ground beneath it.

Parameters
MaxDistanceIf > 0, clamps the point's 2D distance from the character.
Returns
The aim point on the ground
