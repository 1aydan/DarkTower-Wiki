Detailed Description

Base Attribute Set class for Dark Tower.

Does not hold any Gameplay Attribute but provides the shared plumbing: forwarding Pre/PostGameplayEffectExecute to the owner's UDTAbilityCoreComponent, execution-data extraction, clamping helpers and max-attribute adjustment.
