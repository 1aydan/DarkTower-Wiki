◆ EDTNotificationAccumulationMode

enum class EDTNotificationAccumulationMode : uint8
strong

Controls how an incoming notification merges with an existing active notification that shares the same valid DeduplicationKey.

Enumerator
Replace 

Fully replace the active entry's text, value and icon.

Lifetime is reset to the new message's effective lifetime.

Accumulate 

Add NumericValue to the active entry's running total.

BP_Update is called with the new accumulated total and update count. Lifetime is reset.

Max 

Keep whichever numeric value is higher (new vs current accumulated value).

Lifetime is reset.
