◆ ExecutePresetImmediate()

void UDTTargetingComponent::ExecutePresetImmediate ( UTargetingPreset * TargetingPreset,
const FTargetingRequestDelegate & OnComplete )

Build and immediately execute a targeting preset, routing completion to the caller's delegate.

Stateless: does not change the current target, populate LastFoundTargets, or broadcast component delegates. Execution is synchronous, so OnComplete fires before this returns; the request handle is released afterward. Intended for one-shot ability queries (e.g. a melee swing volume) where the caller owns result handling. Read results inside OnComplete via GetHitResultsFromHandle.

Parameters
TargetingPresetThe preset to run (nullptr = DefaultTargetingPreset)
OnCompleteDelegate invoked with the completed request handle

void UDTTargetingComponent::ExecutePresetImmediateWithContext ( UTargetingPreset * TargetingPreset,
const FTargetingSourceContext & SourceContext,
const FTargetingRequestDelegate & OnComplete )

Build and immediately execute a targeting preset using an explicit, caller-supplied source context.

Same stateless one-shot semantics as ExecutePresetImmediate, but lets abilities drive cast-at-location / directional targeting by feeding in a context whose SourceLocation is an aim point. Execution is synchronous; OnComplete fires before this returns. Read results inside OnComplete via the request handle.

Parameters
TargetingPresetThe preset to run (nullptr = DefaultTargetingPreset)
SourceContextThe source context to seed the request with (see ResolveSourceContext)
OnCompleteDelegate invoked with the completed request handle
