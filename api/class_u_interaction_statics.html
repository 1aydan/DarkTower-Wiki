int32 UInteractionStatics::SelectBestInteractableIndex ( AActor * Interactor,
const TArray< AActor * > & Candidates,
const TArray< float > & Priorities )
static

Picks the best interactable among an already-valid candidate set, using the interactor's input device: mouse - the candidate under the cursor, else the one nearest the cursor ground point; gamepad - highest priority, then candidates the player is facing (in front beats behind), then nearest.

Parameters
InteractorThe interacting pawn (used for device, cursor, location and facing).
CandidatesAlready-valid candidate actors (parallel to Priorities).
PrioritiesPer-candidate interaction priority (parallel to Candidates).
Returns
index into Candidates of the winner, or INDEX_NONE if empty.
