FVector UDTBlueprintLibrary::GetSpreadDirection ( const FVector & Forward,
int32 Index,
int32 Count,
float TotalSpreadDegrees )
static

Returns one normalized direction from an evenly spaced horizontal spread around world up.

Spreads below 360 degrees are centered on Forward. A 360-degree spread starts at Forward and distributes unique directions around the full circle without duplicating the first direction.

Parameters
ForwardThe center direction of the spread. A zero vector produces a zero vector.
IndexZero-based index of the direction to return.
CountTotal number of directions in the spread. Values less than or equal to zero produce a zero vector.
TotalSpreadDegreesTotal spread angle, clamped to the range [-360, 360]. A negative value reverses ordering.
Returns
The normalized spread direction, or a zero vector when Forward is zero or Count is not positive.

Returns normalized directions evenly distributed across a horizontal spread around world up.

Spreads below 360 degrees are centered on Forward. A 360-degree spread begins at Forward and generates a complete ring of unique directions suitable for radial traces from one origin.

Parameters
ForwardThe center direction of the spread. A zero vector produces zero-vector entries.
CountNumber of directions to generate. Values less than or equal to zero return an empty array.
TotalSpreadDegreesTotal spread angle, clamped to the range [-360, 360]. A negative value reverses ordering.
Returns
The generated spread directions in angular order around world up.
