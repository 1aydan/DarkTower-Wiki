Detailed Description

Ground-trace target actor that aims at the player's mouse cursor (or, on gamepad, along the current aim direction) instead of the camera forward vector — the correct behaviour for DarkTower's top-down view.

Produces a ground location for cast-at-location abilities and drives the reticle to follow the cursor. Aim resolution is delegated to ADTPlayerCharacter::GetAimGroundLocation so mouse/gamepad handling lives in one place. Falls back to the engine camera trace for non-player avatars.
