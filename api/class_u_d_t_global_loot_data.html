float UDTGlobalLootData::MinStatScale = 0.7f

Bottom of the base-stat roll window as a fraction of the floor-appropriate ceiling (ScaledMin = ScaledMax * MinStatScale).

Higher = tighter base-stat variance among same-floor drops; lower = wider spread. e.g. 0.7 -> deep-floor rolls stay within ~1.4x of each other.
