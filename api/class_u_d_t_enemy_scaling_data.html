float UDTEnemyScalingData::ComputeBandedMultiplier ( int32 EnemyLevel,
TFunctionRef< float(const FDTEnemyScalingBand &)> RateGetter ) const
private

Walks ScalingBands and returns the continuous, compounding stat multiplier for a level.

Each band contributes growth only for the levels inside it and picks up from the previous band's running total, so the curve has no cliffs at breakpoints; the final band's rate continues for all levels beyond it.

Parameters
EnemyLevelThe enemy level to evaluate (equals floor).
RateGetterSelects which per-band growth rate to compound (life / damage / armor).
Returns
The multiplier over base for this level, clamped finite for safety.

◆ ScalingBands

TArray<FDTEnemyScalingBand> UDTEnemyScalingData::ScalingBands

Piecewise growth curve for life / damage / armor, keyed to EnemyLevel (== floor) breakpoints.

This is the single source of truth for the whole difficulty curve — steep early bands for differentiation, and an accelerating endgame tail so enemy stats outrun the (roughly linear) player gear curve and form an infinite-scaling soft wall. Must be sorted ascending by MaxLevel.
