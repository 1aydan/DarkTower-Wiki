Detailed Description

Interface for world actors the player can interact with (loot, chests, levers, NPCs).

Fully implementable in C++ or Blueprint.

void IDTInteractableTarget::GatherInteractionOptions ( const FInteractionQuery & InteractQuery,
TArray< FInteractionOption > & OutOptions )

Return the interaction options this target offers (grantable abilities, GAS-event targets, prompt widgets).

Designers can build/return the array in Blueprint. Leave it empty to fall back to the synthesized direct-interact option. The caller stamps InteractableTarget on each returned option.
