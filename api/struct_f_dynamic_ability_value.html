Detailed Description

One unified ability value, authored on UDTAbilityDefinition::DynamicValues.

It is BOTH the gameplay number (looked up by ValueTag via UDTGameplayAbility::GetDynamicValueByTag) AND its own tooltip placeholder (Placeholder fills a {token} in the ability's Description).

The number is always the combination of its Contributions: each contribution is resolved by its own Value Source (Attribute = coefficient x attribute, Scalable Float, Range) and folded in by its Operation — Add contributions are summed, Multiply scale the sum, Override replaces it. A simple value is just a single contribution; e.g. { +20% Magic, +50% Physical } = 0.2*Magic + 0.5*Physical.
