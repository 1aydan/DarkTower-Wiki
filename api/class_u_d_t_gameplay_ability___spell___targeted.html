◆ TargetActorClass

TSubclassOf<AGameplayAbilityTargetActor> UDTGameplayAbility_Spell_Targeted::TargetActorClass
protected

Target actor used to pick the cast location.

Must be a CONCRETE trace actor that implements PerformTrace (e.g. AGameplayAbilityTargetActor_GroundTrace or _SingleLineTrace, or a Blueprint child of those). Do NOT use the abstract AGameplayAbilityTargetActor_Trace base — its PerformTrace is pure-virtual and will assert on the first tick. If unset, falls back to the avatar's aim point (no interactive reticle).
