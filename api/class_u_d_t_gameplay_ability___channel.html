Detailed Description

Base class for sustained "channel" abilities (e.g.

whirlwind, channeled beam/heal).

On activation it commits cost/cooldown, plays the ability montage (looping the ChannelLoopSection), optionally applies a periodic resource-drain GameplayEffect (mana over time) and adds a looping cue, then holds the channel open until one of these end conditions is met:

  • Input: Hold mode ends on input release; Toggle mode ends on the next input press.
  • Resource: the watched attribute (Mana by default) drops to/under ChannelEndResourceThreshold.
  • Duration: MaxChannelDuration elapses (0 = unlimited).
  • Interrupt: the montage is interrupted/cancelled, or the ability is cancelled externally.

While channeling, K2_OnChannelTick fires every ChannelTickInterval — child abilities apply their per-tick effect (deal damage, spawn VFX, etc.) there. Resource/duration end conditions are evaluated on the authority; input end conditions are driven by the input tasks on the owning client.
