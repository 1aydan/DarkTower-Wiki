Detailed Description

Data-driven modular targeting configuration for a spell.

When a TargetingPreset is set, the spell's default DoSpellEffect runs the preset (via UDTAbilityTask_PerformTargeting) and surfaces the resolved targets through K2_OnSpellTargetsAcquired; child classes decide what effects to apply.
