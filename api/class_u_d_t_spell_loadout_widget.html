Detailed Description

Loadout (skill-tree/assignment) screen for spells.

ESO-style: shows ONE spell bar for the "editing" weapon set, with a toggle (the bar-swap button) to switch which set is being edited. Mirrors UDTAbilityBarWidget — it spawns a row of UDTSpellLoadoutSlotWidgets into a panel — but those slots read/write the per-weapon-set spell store on UDTAbilitySlotComponent, so it edits either set (including the inactive one) without touching combat state.
