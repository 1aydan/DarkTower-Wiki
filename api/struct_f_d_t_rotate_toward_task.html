bool FDTRotateTowardTask::bClearFocusOnExit = true

If true, the AI controller's Gameplay focus will be cleared when this task exits.

Only relevant when bRotateActorDirectly is false. Disable this if another system (e.g. a combat service) manages focus independently.

◆ bRotateActorDirectly

bool FDTRotateTowardTask::bRotateActorDirectly = false

When true, the task rotates the pawn actor directly via SetActorRotation each tick instead of delegating to AAIController::SetFocus.

The interpolation speed is sourced from the pawn's UCharacterMovementComponent::RotationRate.Yaw. Useful when you want the task to own rotation without touching the AI focus system.
