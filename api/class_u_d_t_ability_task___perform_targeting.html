Detailed Description

Reusable ability task that runs a UTargetingPreset and surfaces the resulting hits to the ability.

Resolves the targeting source context from an EDTTargetSourceMode (self / aim location / aim direction / current target) and, when bServerValidate is set, performs the standard GAS client-predict / server-validate target-data round trip:

  • Predicting client: gathers hits locally and ships them to the server, then ends.
  • Authority for a remote avatar: waits for the replicated target data, then broadcasts.
  • Authority+local / standalone: gathers locally and broadcasts immediately.

OnTargetsReady only fires where effects are expected to be applied (authority, or any peer when bServerValidate is false), so the consumer can apply gameplay effects directly in the handler.
