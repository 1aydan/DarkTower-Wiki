Detailed Description

Payload for drag-and-drop operations involving abilities.

Used by both the ability bar (DTAbilityWidget) and skill tree nodes (DTSkillTreeNodeWidget) so that abilities can be dragged from the skill tree and dropped onto ability bar slots.
