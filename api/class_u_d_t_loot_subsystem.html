◆ RollAffixTierAlpha()

float UDTLootSubsystem::RollAffixTierAlpha ( float EffectiveFloor) const
protected

Roll an affix's normalized magnitude alpha using the floor-scaled tier system.

Tier (luck): weighted pick over 1..AffixTierCount where high tiers are always rarest; depth shifts the odds upward (FloorPressure flattens the falloff, capped by MaxFloorPressure). Magnitude (floor scale): the rolled TierFraction is multiplied by AffixPower, which has its own rate and a MinAffixPower floor so a high tier still lands meaningfully even at low floors, then scales further with depth. Uses AffixPower rather than ItemPower so affix pacing is independent.

Parameters
EffectiveFloorFloor after diminishing returns (drives both the tier distribution and AffixPower)
Returns
Alpha = AffixPower * TierFraction, stored as the affix's NormalizedRollValue
