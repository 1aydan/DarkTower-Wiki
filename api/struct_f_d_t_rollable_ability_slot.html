Detailed Description

One rollable ability slot authored on an equipment item.

  • Weapons: TargetAbilitySlot names the weapon ability slot this fills (Primary/Secondary); entries are emitted in slot order so the equip pipeline slots them to left/right-click by index.
  • Other equipment: leave TargetAbilitySlot empty — the ability is granted passively (never slotted).

Static-vs-rolled per slot: if StaticAbility is set the slot is fixed (legendary / mixed); otherwise one candidate is rolled by weight from AbilityPool (a shared FDTAbilityPoolRow DataTable).
