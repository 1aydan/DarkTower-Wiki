Detailed Description

Filter: passes if the Subject actor lies within a directional cone projected from the Reference actor.

DirectionDegrees is a yaw offset from the Reference actor's forward vector: 0 = in front 180 = behind 90 = to the right -90 = to the left

Examples: Behind Target → ReferenceActor=Target, DirectionDegrees=180, HalfAngle=45 In Front → ReferenceActor=Target, DirectionDegrees=0, HalfAngle=60 Right Flank → ReferenceActor=Target, DirectionDegrees=90, HalfAngle=45 Rear-Right → ReferenceActor=Target, DirectionDegrees=135, HalfAngle=45
