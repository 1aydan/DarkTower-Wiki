Detailed Description

Combines PlayMontageAndWait and WaitForEvent into one task: plays a montage and fires EventReceived for any gameplay event matching EventTags while it plays.

Exec-pin delegate names and the factory signature intentionally match the GASCompanion task this replaced, so existing Blueprint latent nodes redirect losslessly.

Play a montage and wait for it to end.

If a gameplay event happens that matches EventTags (or EventTags is empty), the EventReceived delegate will fire with a tag and event data.

Parameters
TaskInstanceNameSet to override the name of this task, for later querying
MontageToPlayThe montage to play on the character
EventTagsAny gameplay events matching this tag will activate the EventReceived callback. If empty, all events will trigger callback
RateChange to play the montage faster or slower
StartSectionChange to montage section to play during montage
bStopWhenAbilityEndsIf true, this montage will be aborted if the ability ends normally. It is always stopped when the ability is explicitly cancelled
AnimRootMotionTranslationScaleChange to modify size of root motion or set to 0 to block it entirely
