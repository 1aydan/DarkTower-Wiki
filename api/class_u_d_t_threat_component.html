Detailed Description

Server-authoritative aggro system for AI controllers.

Accumulates threat per hostile actor (damage taken, first sight, taunts), decays it over time.

void UDTThreatComponent::ApplyTaunt ( AActor * Instigator,
float TopThreatMultiplier = 1.2f )

Force the instigator to the top of the table by setting its threat to the current top threat multiplied by TopThreatMultiplier (never lowering an existing entry).

With a multiplier above the config's OvertakeMultiplier this guarantees an immediate target switch.

Parameters
InstigatorThe taunting actor
TopThreatMultiplierMultiplier applied to the current top threat
