Detailed Description

Event payload wrapper that carries a melee hitbox through FGameplayEventData::TargetData.

Sent by the Melee Hitbox anim notify and consumed by UDTGameplayAbility_Melee. The melee flow itself is local (each machine fires its own anim notifies), but the struct still net-serializes so the payload survives any replicated path GAS routes it through (e.g. event-triggered ability activation RPCs).
