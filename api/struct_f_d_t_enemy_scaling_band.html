Detailed Description

A single segment of the piecewise enemy scaling curve.

Bands are applied in ascending order over EnemyLevel (which equals floor below the soft cap). Each band contributes compounding growth only for the levels that fall inside it, and the curve is continuous because each band starts from the multiplier the previous band ended on. The highest band's rates continue for every level beyond it, so endgame stays bounded and tunable.

Use higher rates in the early bands (so the first biomes feel distinct) and lower rates in the later bands (so late floors don't balloon) — something a single global exponential rate can't do.
