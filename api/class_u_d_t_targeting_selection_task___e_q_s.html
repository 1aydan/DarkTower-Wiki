Detailed Description

EQS-driven selection task.

Runs an Environment Query from the source context and maps the resulting actors (or locations, if the query returns points) into the targeting result set.

EQS runs asynchronously, so presets using this task MUST be executed via the async targeting path (e.g. UDTAbilityTask_PerformTargeting with bUseAsync = true). Running it through an immediate request will complete before the query returns and yield no targets.
