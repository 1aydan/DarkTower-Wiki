◆ AbilitySet

TObjectPtr<UDTAbilitySet> UDTAbilityDefinition::AbilitySet

Grantable payload for this ability (abilities/attributes/effects/owned tags).

Embedding it here makes this GUID-addressable definition the single glue between loot rolls, the saved item, the gameplay grant, and the tooltip. For an ability used in a weapon slot, this set should grant exactly ONE UGameplayAbility (one set == one granted handle == one weapon ability slot).
