static

Formats an ability's Description template using its TooltipValues.

AbilityContext (typically the ability itself or its CDO) is the object that "Ability Property" sourced values reflect against; it may be null, in which case only Range/Scalable values resolve. The definition is never required to reference the ability.

Like FormatAbilityDescription, but renders each value as a "current -> next" upgrade preview between two levels (EX: "Deal 50 -> 70 Fire damage").

Only level-varying values (ScalableFloat, or Ability Property values backed by an FScalableFloat) change across the arrow; flat values render the same on both sides.
