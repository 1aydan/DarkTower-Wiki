int32 EvaluationLevel = 0,
const AActor * SourceActor = nullptr )
static

Formats an ability's Description template using its DynamicValues (each fills a {Placeholder}).

SourceActor supplies the ASC that Attribute-sourced values read from (and that AbilityValue references resolve against); it may be null, in which case Attribute values resolve to 0. The definition is never required to reference the ability.

Like FormatAbilityDescription, but renders each value as a "current -> next" upgrade preview between two levels (EX: "Deal 50 -> 70 Fire damage").

Only level-varying values (ScalableFloat, or Attribute coefficients backed by a curve) change across the arrow; flat values render the same on both sides.
